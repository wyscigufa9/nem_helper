# Grenade Helper

A grenade helper for Nemesis with saved lineups, aim assistance, and automatic throws.

## Installation

1. Download [install.ps1](https://github.com/wyscigufa9/nem_helper/blob/main/install.ps1).
2. Run `install.ps1`.
3. Done! Your Grenade Helper is ready to use.

The installer automatically downloads all required grenade icons into `Documents\nem\scripts\images`.

**Note:** Installing the icons is required for Grenade Helper to work correctly.
